1. Put the entire CHS system on the page

Let k\in\{C,N\} index cognitive and noncognitive skills. A compact version of the full system is

\begin{aligned} Z_{1,k,t,j,i} &= \mu_{1,k,t,j}+\alpha_{1,k,t,j}\ln\theta_{k,t,i} +\varepsilon_{1,k,t,j,i},\\ Z_{2,t,j,i} &= \mu_{2,t,j}+\alpha_{2,t,j}\ln I_{t,i} +\varepsilon_{2,t,j,i},\\ Z_{3,k,j,i} &= \mu_{3,k,j}+\alpha_{3,k,j}\ln\theta_{k,P,i} +\varepsilon_{3,k,j,i},\\ Z_{4,j,i} &= g_j(\theta_{C,T,i},\theta_{N,T,i},X_i)+\varepsilon_{4,j,i},\\ \ln I_{t,i} &= q_t(\ln\boldsymbol\theta_{t,i}, \ln\boldsymbol\theta_{P,i},Y_{t,i})+\eta_{I,t,i},\\ \theta_{k,t+1,i} &= \left[\sum_{\ell=1}^{5}\gamma_{k,t,\ell} X_{k,t,\ell,i}^{\varphi_{k,t}}\right]^{1/\varphi_{k,t}} \exp(\eta_{k,t+1,i}). \end{aligned}

The five CES inputs are current cognitive skill, current noncognitive skill, current investment, maternal cognitive skill, and maternal noncognitive skill. Measurement errors, investment shocks, production shocks, and the initial latent-factor distribution complete the probability model.

GMM vs MLE (or even GLS!)

GMM selects implications of the equations, such as means, covariances, and orthogonality restrictions:

E[m_i(\psi)]=0, \qquad \widehat\psi_{GMM} =\arg\min_\psi\bar m(\psi)'W\bar m(\psi).

MLE specifies the joint densities and integrates over the unobserved state \mathcal X_i:

L_i(\psi)=\int p(Z_i,\mathcal X_i\mid X_i;\psi)\,d\mathcal X_i, \qquad \widehat\psi_{ML}=\arg\max_\psi\sum_i\log L_i(\psi).

GMM MLE
Uses Selected moments implied by the system Entire specified joint density
Distribution Does not require every density to be specified Requires distributional assumptions or a flexible approximation
Latent factors Recovered through covariance and higher-moment restrictions Integrated out of the likelihood
Trade-off More robust to density misspecification Potentially more efficient, but computationally heavier

This notebook follows the MLE factorization because it makes every likelihood contribution visible. It is a pedagogical full-information representation; it should not be confused with a claim that the original CHS replication code is one black-box simultaneous optimizer.

2. Measurement system: identify signal from covariance

For three measures of one factor,

Z_j=\lambda_j\theta+\epsilon_j,\qquad \lambda_1=1,

conditional independence gives

\begin{aligned} \operatorname{Cov}(Z_1,Z_2)&=\lambda_2\operatorname{Var}(\theta),\\ \operatorname{Cov}(Z_1,Z_3)&=\lambda_3\operatorname{Var}(\theta),\\ \operatorname{Cov}(Z_2,Z_3)&=\lambda_2\lambda_3 \operatorname{Var}(\theta). \end{aligned}

Therefore the factor variance and loadings can be written directly in terms of observed covariances:

\operatorname{Var}(\theta)=\frac{S_{12}S_{13}}{S_{23}},\qquad \lambda_2=\frac{S_{23}}{S_{13}},\qquad \lambda_3=\frac{S_{23}}{S_{12}}.

The next calculation uses actual PIAT Mathematics, PIAT Reading Recognition, and PPVT scores at ages 5–6.

The cognitive and noncognitive production densities evaluate how close the next latent skills are to the CES predictions.

Recall that the entries of x are in logs. Define

c_t=x[\texttt{Ct}],\quad n_t=x[\texttt{Nt}],\quad i_t=x[\texttt{I}],\quad p_C=x[\texttt{PC}],\quad p_N=x[\texttt{PN}].

The level inputs passed to the CES function are therefore

X(x)=\left(e^{c_t},e^{n_t},e^{i_t},e^{p_C},e^{p_N}\right).

The conditional mean of next-period log cognitive skill is

\begin{aligned} \mu_{C1} &=\log\!\left[ \sum_{\ell=1}^{5}\gamma_{C,\ell}X_\ell(x)^{\phi_C} \right]^{1/\phi_C}\\ &=\frac{1}{\phi_C}\log\!\left[ \gamma_{C,1}e^{\phi_Cc_t} +\gamma_{C,2}e^{\phi_Cn_t} +\gamma_{C,3}e^{\phi_Ci_t} +\gamma_{C,4}e^{\phi_Cp_C} +\gamma_{C,5}e^{\phi_Cp_N} \right]. \end{aligned}

With the candidate values used below, this becomes

\mu_{C1}=\frac{1}{0.35}\log\!\left[ 0.30e^{0.35c_t}+0.15e^{0.35n_t}+0.25e^{0.35i_t} +0.20e^{0.35p_C}+0.10e^{0.35p_N} \right].

Likewise, the conditional mean of next-period log noncognitive skill is

\mu_{N1}=\frac{1}{0.20}\log\!\left[ 0.15e^{0.20c_t}+0.35e^{0.20n_t}+0.25e^{0.20i_t} +0.10e^{0.20p_C}+0.15e^{0.20p_N} \right].

The code implements these two expressions literally: exp() converts the log states to levels, the weighted power sum calculates the CES output, and the outer log() returns to the log-skill scale used by x["C1"] and x["N1"].

gamma_C <- c(0.30, 0.15, 0.25, 0.20, 0.10); phi_C <- 0.35
gamma_N <- c(0.15, 0.35, 0.25, 0.10, 0.15); phi_N <- 0.20

5. CHS-style computation: integrate, then maximize

The node above is not an estimate. The observed-data likelihood integrates over all possible latent states:

L_i(\psi)=\int p(Z_i,\mathcal X_i;\psi)\,d\mathcal X_i.

This integral is the central computational object. For every trial value of \psi, the estimator evaluates a large complete-data likelihood at many latent paths, integrates those paths for every child, sums the marginal log likelihoods, and then changes \psi and starts again.

\boxed{ \psi \longrightarrow \left\{p(Z_i,\mathcal X_i^{(b)};\psi)\right\}_{i,b} \longrightarrow \left\{L_i(\psi)\right\}_i \longrightarrow \sum_i\log L_i(\psi) }

The code below uses sequential Monte Carlo. Drawing from the initial, investment, and production densities makes the marginal likelihood the average of the remaining measurement and adult-outcome densities.

set.seed(20260902); B <- 20000L
draw <- data.frame(PC = rnorm(B), PN = rnorm(B),
  Ct = rnorm(B), Nt = rnorm(B))
draw$I <- beta_I[1] + beta_I["Ct"] * draw$Ct + beta_I["Nt"] * draw$Nt +
  beta_I["PC"] * draw$PC + beta_I["PN"] * draw$PN + rnorm(B, 0, sd_I)

index_C <- rowSums(sweep(Xdraw^phi_C, 2, gamma_C, "*"))

For the whole sample,

\ell(\psi)=\sum_{i=1}^{n}\log L_i(\psi).

An optimizer changes the measurement, investment, production, shock, and initial-distribution parameters, recomputes all L_i(\psi), and searches for the parameter vector that maximizes this sum. The computational difficulty is not any single density. It is repeatedly performing a high-dimensional integration for every child while respecting normalizations and parameter constraints.

6. The Agostinelli–Wiswall alternative

Agostinelli–Wiswall do not require an individual posterior assignment of \theta_i inside the production-function estimator. Their sequential approach first links the measurement scales across ages and then substitutes rescaled noisy measures into the structural equations. Alternative measures of the same latent factor serve as instruments for the primary measure.

Suppose the rescaled primary measures are

\widetilde Z_{\theta,t,1}=\ln\theta_t+e_{\theta,t,1}, \qquad \widetilde Z_{I,t,1}=\ln I_t+e_{I,t,1}.

Start from the latent translog technology,

\ln\theta_{t+1} = a_t+\gamma_{1,t}\ln\theta_t +\gamma_{2,t}\ln I_t +\gamma_{3,t}\ln\theta_t\ln I_t +\eta_{\theta,t+1}.

Because

\ln\theta_t=\widetilde Z_{\theta,t,1}-e_{\theta,t,1}, \qquad \ln I_t=\widetilde Z_{I,t,1}-e_{I,t,1}, \qquad \widetilde Z_{\theta,t+1,1} =\ln\theta_{t+1}+e_{\theta,t+1,1},

direct substitution gives

\begin{aligned} \widetilde Z_{\theta,t+1,1} ={}&a_t +\gamma_{1,t}\left(\widetilde Z_{\theta,t,1}-e_{\theta,t,1}\right) +\gamma_{2,t}\left(\widetilde Z_{I,t,1}-e_{I,t,1}\right)\\ &+\gamma_{3,t} \left(\widetilde Z_{\theta,t,1}-e_{\theta,t,1}\right) \left(\widetilde Z_{I,t,1}-e_{I,t,1}\right) +\eta_{\theta,t+1}+e_{\theta,t+1,1}. \end{aligned}

Collecting all terms involving measurement errors into the composite error (u_{t+1}) gives

\begin{aligned} \widetilde Z_{\theta,t+1,1} ={}&a_t+\gamma_{1,t}\widetilde Z_{\theta,t,1} +\gamma_{2,t}\widetilde Z_{I,t,1}\\ &+\gamma_{3,t}\widetilde Z_{\theta,t,1} \widetilde Z_{I,t,1}+u_{t+1}, \end{aligned}

where

\begin{aligned} u_{t+1} ={}&\eta_{\theta,t+1}+e_{\theta,t+1,1} -\gamma_{1,t}e_{\theta,t,1} -\gamma_{2,t}e_{I,t,1}\\ &-\gamma_{3,t}\left( \widetilde Z_{\theta,t,1}e_{I,t,1} +\widetilde Z_{I,t,1}e_{\theta,t,1} -e_{\theta,t,1}e_{I,t,1} \right). \end{aligned}

Substituting them into a translog technology gives

\begin{aligned} \widetilde Z_{\theta,t+1,1} ={}&a_t+\gamma_{1,t}\widetilde Z_{\theta,t,1} +\gamma_{2,t}\widetilde Z_{I,t,1}\\ &+\gamma_{3,t}\widetilde Z_{\theta,t,1} \widetilde Z_{I,t,1}+u_{t+1}. \end{aligned}

The first skill and investment measures are endogenous regressors because their measurement errors enter u_{t+1}. Under independent measurement errors, second measures contain the same latent signals but are orthogonal to those errors. This produces IV moments such as

E\!\left[ Q_{i,t} \left( \widetilde Z_{\theta,t+1,1} -X_{i,t}'\gamma_t \right) \right]=0,

where a simple instrument vector is

Q_{i,t}=\left( 1, \widetilde Z_{\theta,t,2}, \widetilde Z_{I,t,2}, \widetilde Z_{\theta,t,2}\widetilde Z_{I,t,2} \right)'.

A small IV calculation with the actual measures

The following code illustrates the computational skeleton. PIAT Mathematics is the primary skill measure, PIAT Reading Recognition is its alternative measure, and two different HOME indices play the analogous investment roles. The same baseline transformation is applied to Mathematics at both ages so that growth is not mechanically removed by period-specific standardization.

aw <- analysis
math_mu <- mean(aw$piat_math_raw_t); math_sd <- sd(aw$piat_math_raw_t)
aw$skill_t <- (aw$piat_math_raw_t - math_mu) / math_sd
aw$skill_tp1 <- (aw$piat_math_raw_tp1 - math_mu) / math_sd
aw$skill_iv <- as.numeric(scale(aw$piat_reading_recognition_raw_t))
aw$invest_t <- as.numeric(scale(aw$home_total_z_t))
aw$invest_iv <- as.numeric(scale(aw$home_cognitive_z_t))
# Primary measures enter X; alternative measures enter Q.
y_aw <- aw$skill_tp1
X_aw <- cbind(1, aw$skill_t, aw$invest_t, aw$skill_t * aw$invest_t)
Q_aw <- cbind(1, aw$skill_iv, aw$invest_iv, aw$skill_iv * aw$invest_iv)
A_aw <- crossprod(Q_aw, X_aw)
b_aw <- crossprod(Q_aw, y_aw)
W_aw <- solve(crossprod(Q_aw))
gamma_aw <- solve(t(A_aw) %*% W_aw %*% A_aw,
  t(A_aw) %*% W_aw %*% b_aw)
aw_result <- data.frame(
  parameter = c("Intercept", "Skill", "Investment", "Skill x Investment"),
  estimate = as.numeric(gamma_aw))
kable(aw_result, digits = 3)
parameter estimate

This numerical result is not an AW replication. It illustrates the estimator’s logic with our extract. A proper application must estimate and test the age-invariant measurement restrictions, use the paper’s full instrument set, allow for missing observations, and address economic endogeneity separately from measurement error.

What changes computationally?

CHS-style latent likelihood Agostinelli–Wiswall
Individual skill Remains latent inside L_i(\psi) Replaced by a rescaled noisy measure
Measurement error Handled by integrating the latent state Handled with alternative measures as IVs
Production estimation Transition density inside a large likelihood Sequential IV/GMM production equation
Main computation High-dimensional integration for each child Matrix moments and recursive IV steps
Essential scale restriction Factor normalization Age-invariant measures linking periods

The contrast is therefore not latent skills'' versusobserved skills.’’ Both approaches treat skills as latent. The distinction is whether the estimator integrates latent histories or eliminates them from the estimating equations using transformed measures and moment restrictions.

What this notebook has and has not done

  • It uses actual NLSY/CYA child, HOME, maternal, schooling, wage, and conviction observations.
  • It displays every density block in a CHS-style likelihood and integrates the latent state for one actual child.
  • It does not pretend that standardized observed measures are latent-factor scores.
  • It does not yet reproduce the full CHS estimates. Full replication requires all periods, CHS’s distributional specification, missing-data treatment, anchoring choices, endogeneity treatment, and constrained optimization.
  • It now shows the computational skeleton of the Agostinelli–Wiswall sequential IV alternative, but does not claim to reproduce their estimates.
